# Spider Chart (Radar Chart) Design & Engineering Skill

이 스킬은 한국형 직무 스트레스(KOSS) 및 마음건강 8대 지표를 5단계 파스텔 틴트 가이드와 호버 인터랙티브 툴팁으로 시각화하는 SVG 스파이더 차트 표준 스펙을 정의합니다.

## 핵심 가이드라인

1. **360도 전역 소프트 파스텔 원형 무지개 그라데이션 (360° Soft Pastel Conic Rainbow Gradient)**:
   - 특정 방향/위치에 치우치지 않고 차트 중심(50%, 50%)을 축으로 8대 전 영역 둘레에 360도 은은하게 순환하는 소프트 파스텔 무지개 그라데이션 적용:
     - `0°`: 소프트 파스텔 로즈 `#FF9EB0`
     - `51°`: 소프트 피치 살구 `#FFBEA6`
     - `102°`: 부드러운 멜론 오렌지 `#FFD896`
     - `154°`: 따뜻한 밀크 옐로우 `#FFF0A3`
     - `205°`: 차분한 소프트 세이지 민트 `#B7F2CE`
     - `257°`: 맑은 소프트 베이비 스카이 `#B0D5FC`
     - `308°`: 은은한 소프트 라벤더 `#D8B8F8`
     - `360°`: 소프트 파스텔 로즈 `#FF9EB0`
   - 눈이 편안한 단아한 소프트 파스텔 톤으로 8대 축 전 영역에 무지개 컬러가 자연스럽고 고르게 펼쳐집니다.

2. **Border-less 맑은 시각화**:
   - 데이터 라인은 `#00C474` 에메랄드 2.8px 선과 흰색 보더가 들어간 정점으로 투명하고 또렷하게 표출합니다.

3. **전역 재사용**:
   - `src/components/ui/BklitRadarChart.tsx` (또는 `SpiderChart.tsx`)에서 공통 제공하며, 온보딩 결과 뷰(`KossResultView.tsx`)와 내 정보 뷰(`MyPageSheet.tsx`)에 동기화 적용됩니다.
