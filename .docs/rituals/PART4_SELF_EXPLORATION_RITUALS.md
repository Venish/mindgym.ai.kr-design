# 🟠 [RITUAL-PART 4] 나를 더 알고 싶은 사람을 위한 리추얼 (33 ~ 45번)

본 문서는 흩어져 있던 기질과 욕구, 패턴을 모아 입체적인 자기 이해에 이르도록 돕는 **33번부터 45번 리추얼의 원본 내용 및 웹 UI 구현 스펙 문서**입니다.

---

## 33. 존재소개 (100 Identity Sentences)
* **추천 대상**: 내가 어떤 사람인지 알고 싶고 구체적인 자기 정의가 필요한 사람.
* **방법**: '나는 ___한 사람이다'의 빈칸을 매일 하나씩 채워 50개, 100개 문장으로 축적합니다.
* **효과**: 쉽게 떠오르던 답을 지나 깊은 곳의 나까지 끌어올려 입체적인 내 모습을 발견합니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 100개 빈칸 문장 수집 칩 뷰. 매일 1문장 입력 시 100개 모자이크 조각이 맞춰지는 비주얼.

---

## 34. 나 사용설명서 (Personal User Manual)
* **추천 대상**: 자신을 다루는 법을 몰라 매번 같은 방식으로 지치는 사람.
* **방법**: 나의 타고난 성능(기질)과 AS법(방전 시 회복 방법)을 제품 설명서처럼 정리합니다.
* **효과**: 힘들 때 나에게 맞는 회복법을 즉각 꺼내 쓰며 자책과 에너지 낭비를 방지합니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 제품 사양서 2열 카드 뷰 ([타고난 기질] vs [나의 AS 회복법]).

---

## 35. 나만의 집그리기 (House Blueprint of Desires)
* **추천 대상**: 내가 무엇을 가장 원하는지 삶의 우선순위가 헷갈리는 사람.
* **방법**: 방이 10개인 집 도면을 그리고, 방을 하나씩 줄여 최종 3개까지 남는 '마지막 공간'을 확인합니다.
* **효과**: 끝까지 포기하지 못하는 것을 통해 내가 진짜 중요하게 여기는 핵심 욕구를 파악합니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 10칸 룸 드로잉 & 포기 인터랙션. 클릭할 때마다 룸이 닫히며 최종 3개 필수 룸 하이라이트.

---

## 36. 자기인식상태점검 (Self-Awareness Balance Check)
* **추천 대상**: 자신에 대해 과대해석 하거나 과소평가하여 자기 이해가 치우친 사람.
* **방법**: 종이를 반으로 나누어 '내가 나라서 좋은 점'과 '내가 고치고 싶은 부끄러운 점'을 같은 시간 적습니다.
* **효과**: 내 시선이 긍정과 부정 중 어디로 기울어 있는지 한눈에 한계와 장점을 파악합니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 양팔 저울 2열 비교 카드 뷰. 장점과 부끄러운 점 문항 수에 따라 저울이 기울어지는 비주얼.

---

## 37. 셀프 QnA (Random Self-Questioning)
* **추천 대상**: 무엇을 써야 할지 막막해서 기록을 시작하지 못하는 사람.
* **방법**: 매일 질문 카드 1장을 뽑아 그 질문에 답하는 랜덤 질문 리추얼입니다.
* **효과**: 질문이 탐색의 랜턴 역할을 하여 평소 들여다보지 않던 마음의 구석을 비춥니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 3D 질문 카드 덱 드로우. "오늘의 질문 카드 뽑기" 탭 시 카드가 뒤집히며 질문 노출.

---

## 38. 자문자답 글쓰기 (Self-Dialogue via 2 Accounts)
* **추천 대상**: 자기 고민을 객관적으로 보기 어려운 사람.
* **방법**: 질문하는 사람(상담자)과 답하는 사람(내담자) 2개의 역할을 오가며 시차 대화를 나눕니다.
* **효과**: 나를 시간차를 두고 분리하여 마치 타인의 고민을 상담하듯 문제를 바라보게 돕습니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 1인 2역 채팅 메신저 인터페이스 (질문자 아바타 💬 vs 답하는 나 아바타 💬).

---

## 39. 과거분석표 (Past Decision Matrix)
* **추천 대상**: 같은 실수나 선택 패턴을 반복한다고 느끼는 사람.
* **방법**: 과거의 선택 순간, 선택 이유, 막상 선택하니 달랐던 점, 배운 점을 표로 작성합니다.
* **효과**: 후회하던 선택 패턴을 직관적으로 파악하여 반복을 끊어내는 첫걸음을 뗍니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 4열 패턴 분석 표 작성 매트릭스 카드.

---

## 40. 에너지 가계부 (Energy Account Book)
* **추천 대상**: 늘 이유 없이 지쳐 있고 무기력한 사람.
* **방법**: 나를 기 빨리게 한 것(지출부)과 나를 충전해준 것(수입부)을 돈처럼 수치로 적어 정산합니다.
* **효과**: 에너지 수입과 지출을 눈으로 확인하여 충전을 늘리고 소모를 줄이는 선택을 하게 돕습니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 에너지 가계부 계산기. [지출 -40 (야근)] + [수입 +20 (산책)] ➔ "오늘의 잔여 에너지 -20" 디스플레이.

---

## 41. 저자소개 독서법 (Author Profile Collection)
* **추천 대상**: 진로나 인생 방향이 막막한 청소년 및 청년.
* **방법**: 책 본문 대신 책날개의 '저자 소개'만 20~30개 모아 읽어 타인의 인생 경로를 탐색합니다.
* **효과**: 인생에 정해진 길은 없으며 다양한 수많은 갈래가 있음을 깨닫게 됩니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 저자 커리어 수집 갤러리 카드 뷰.

---

## 42. 모닝 드로잉 (Morning Intuitive Drawing)
* **추천 대상**: 생각이 너무 많아 아침부터 머리가 무거운 사람.
* **방법**: 아침 기상 직후 1분간 알람을 맞추고 마음대로 지금 이 순간의 감정을 선이나 원으로 그립니다.
* **효과**: 검열을 거치지 않는 손의 움직임으로 텍스트보다 직관적인 무의식의 상태를 드러냅니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 1분 자유 선 드로잉 캔버스.

---

## 43. 단어 조합 시 (3-Word Poem Writing)
* **추천 대상**: 감정을 직접 말로 풀기 어려운 사람.
* **방법**: 무작위 단어 3개를 고르고 그 단어를 모두 포함시켜 오늘의 감정을 시나 에세이로 적습니다.
* **효과**: 무작위 제약이 상상력을 자극하여 의외의 자기 표현을 이끌어 냅니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 랜덤 단어 3개 생성 버튼 ➔ 시 작성 원고지 템플릿.

---

## 44. 짝꿍소개 (Partner Interview & Introduction)
* **추천 대상**: 남의 말을 듣기보다 자기 말하기 바쁜 사람.
* **방법**: 펜과 녹음 없이 오직 귀로만 타인의 말을 경청한 뒤 짝꿍을 대신 소개합니다.
* **효과**: 집중 경청을 할 수밖에 없는 환경을 조성하여 깊은 듣기 연습을 돕습니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 경청 타이머 & 짝꿍 소개 템플릿 카드.

---

## 45. 연간 편지 릴레이 (Annual Relay Letter)
* **추천 대상**: 한 해가 어떻게 지나갔는지 모르게 흘려보내는 사람.
* **방법**: 1년 전 내가 보낸 예약 메일을 읽고, 다시 미래의 나에게 답장을 작성해 예약 발송합니다.
* **효과**: 1년 단위로 내 삶을 잇는 지속적인 대화를 나누며 성장을 반추합니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 1년 뒤 도착하는 타임캡슐 편지 예약 발송기.
