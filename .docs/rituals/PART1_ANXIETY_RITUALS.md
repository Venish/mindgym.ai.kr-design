# 🟢 [RITUAL-PART 1] 불안하고 걱정이 많은 사람을 위한 리추얼 (1 ~ 11번)

본 문서는 파국적 상상, 과도한 걱정, 긴장으로 마음이 흔들릴 때 불안을 가라앉히는 **1번부터 11번 리추얼의 원본 내용 및 웹 UI 구현 스펙 문서**입니다.

---

## 1. 미소 명상 (Smile Visualization Meditation)
* **추천 대상**: 마음이 자꾸 부정적인 쪽으로 끌려갈 때, 또는 과도한 긴장을 풀고 싶을 때 좋습니다.
* **방법**: 생각만 해도 저절로 미소가 지어지는 공간, 풍경, 상황을 하나 떠올립니다. 그리고 그 공간 안에 내가 들어가 있는 모습을 천천히 상상하는 시각화 명상입니다.
* **효과**: 우리 뇌는 생생하게 상상한 장면을 실제와 비슷하게 인지하므로 몸의 긴장이 풀립니다.
* **💻 웹 구현 & UI 모습**:
  * **라우트/모듈**: 오디오 가이드형 (`/player/RT-001`)
  * **인터랙션**: 파스텔 그린 앰비언트 빛이 천천히 호흡하듯 퍼지는 캔버스 연출.
  * **UI 컴포넌트**: `AnimatedMorningSun` 스피너 및 미소 짓는 오디오 가이드 자막 싱크.

---

## 2. 마음 챙김 벨 (Mindfulness Bell)
* **추천 대상**: 생각이 꼬리에 꼬리를 물고 멈추지 않는 사람에게 특히 좋습니다.
* **방법**: 타이머를 설정해두면 정해진 시간 동안 무작위로 청아한 종소리가 울립니다. 종소리가 울리면 하던 생각을 잠시 멈추고 그 소리만을 듣습니다.
* **효과**: 종소리가 맥을 끊어주는 청각 자극 역할을 하여 잡생각을 즉시 멈추게 돕습니다.
* **💻 웹 구현 & UI 모습**:
  * **라우트/모듈**: 앰비언트 오디오 팝업 & Web Audio API 싱잉볼 음원
  * **인터랙션**: 종소리가 칠 때 동심원 파동(`Waveform Pulse`)이 퍼지며 3초간 화면 텍스트 일시정지.

---

## 3. 시선고정명상 (Visual Focus Meditation)
* **추천 대상**: 눈을 감는 명상이 오히려 잡생각을 부르는 사람, 카페나 사무실에서 눈 감기 어려운 사람.
* **방법**: 눈을 감지 않고 뜬 채로, 화면의 한 지점을 정해 1분 알람 동안 그것만 바라보는 명상입니다.
* **효과**: 시선을 한 점에 고정하면 시각 정보가 단순해져 잡생각이 비워집니다.
* **💻 웹 구현 & UI 모습**:
  * **라우트/모듈**: 1분 카운트다운 캔버스 모달
  * **인터랙션**: 중앙의 은은한 원형 닷(Dot) 아이콘이 천천히 크기가 변하며 1분 원형 프로그레스 링 카운트다운.

---

## 4. 횡경막 호흡 (Diaphragmatic Breathing)
* **추천 대상**: 긴장되거나 불안이 올라올 때 가장 빠르게 몸을 진정시키고 싶은 사람.
* **방법**: 왼손은 가슴, 오른손은 배에 올리고 1분간 들이쉬고 내쉬는 배 호흡만을 느낍니다.
* **효과**: 깊고 느린 호흡은 부교감 신경을 활성화하여 이완 반응을 직접 켭니다.
* **💻 웹 구현 & UI 모습**:
  * **라우트/모듈**: 호흡 유도 가이드 인터랙티브 원형 링
  * **인터랙션**: "들이쉬고(4초) - 멈추고(4초) - 내쉬고(4초)" 박자에 맞춰 원이 확대/축소되는 비주얼 가이드.

---

## 5. 망할 확률 계산기 (Disaster Probability Calculator)
* **추천 대상**: 작은 일도 최악의 시나리오로 키우는 파국적 상상 성향이 강한 사람.
* **방법**: 걱정되는 상황이 실제로 일어날 확률(%)과 엎친 데 덮친 최악의 확률을 숫자로 직접 계산해 봅니다.
* **효과**: 막연한 불안을 감정의 영역에서 직관적인 계산과 숫자의 영역으로 옮겨 현실 인지를 돕습니다.
* **💻 웹 구현 & UI 모습**:
  * **라우트/모듈**: 계산기 인터랙티브 입력 카드 (`/player/RT-005`)
  * **인터랙션**: [걱정 상황 입력] ➔ [발생 가능성 % 슬라이더 조작] ➔ "실제 파국 확률: 1.2%" 수치 롤링(`NumberTicker`) 표시.

---

## 6. 긍정 만약에 (Positive What-If)
* **추천 대상**: 걱정의 '만약에'에 자주 사로잡히는 사람.
* **방법**: '만약에 이런 일이 일어나면 어쩌지'를 반대로 틀어, 모든 상황이 최상으로 흘러가는 결과를 상상해 적습니다.
* **효과**: 의식적으로 긍정적 결말을 상상해 보면서 마음의 방향성을 선택하는 연습을 합니다.
* **💻 웹 구현 & UI 모습**:
  * **라우트/모듈**: 반전 글쓰기 카드 컴포넌트
  * **인터랙션**: 부정적인 만약에 문장을 입력하면 카드 플립(Flip) 애니메이션과 함께 긍정적 반전 문장 템플릿 생성.

---

## 7. 걱정유통기한라벨링 (Worry Expiration Labeling)
* **추천 대상**: 같은 걱정을 며칠씩 반복해서 끌어안고 압도되는 사람.
* **방법**: 걱정되는 내용을 적고 '아마 이때까지도 이 문제는 해결되지 않았을 것 같다' 싶은 날짜를 라벨로 붙여 보관합니다.
* **효과**: 걱정에 유통기한을 매겨보면 대부분의 걱정이 생각보다 수명이 짧음을 직관적으로 확인하게 됩니다.
* **💻 웹 구현 & UI 모습**:
  * **라우트/모듈**: 디지털 유통기한 라벨 보관함
  * **인터랙션**: 걱정 텍스트 입력 후 [D-7], [D-30] 날짜 라벨 칩을 붙여 D-Day 카운트다운 디스플레이 카드에 보관.

---

## 8. 스트레스 분쇄 (Stress Shredder)
* **추천 대상**: 마음에 쌓인 분노와 응어리를 안전하게 풀어내고 싶은 사람.
* **방법**: 스트레스를 주는 사람이나 상황을 한 줄로 적고, 이를 파쇄기에 넣어 잘게 분쇄합니다.
* **효과**: 종이를 물리적으로 파쇄하는 행위가 시각적·심리적 후련함과 스트레스 해소를 제공합니다.
* **💻 웹 구현 & UI 모습**:
  * **라우트/모듈**: 디지털 문서 파쇄기 인터랙션
  * **인터랙션**: 텍스트 카드를 드래그하여 화면 하단 파쇄기 영역으로 넣으면 사운드와 함께 국수 가닥처럼 잘게 갈려 사라지는 모션.

---

## 9. 걱정 저금통 (Worry Piggy Bank)
* **추천 대상**: 걱정을 당장 해결해야 한다는 조급함에 시달리는 사람.
* **방법**: 걱정거리를 적어서 저금통에 넣고, 저금통이 가득 차면 한 번에 꺼내어 확인합니다.
* **효과**: 걱정을 잠시 맡겨두는 행위를 통해 지금 당장 집착하지 않고 내려놓는 습관을 기릅니다.
* **💻 웹 구현 & UI 모습**:
  * **라우트/모듈**: 3D 디지털 저금통 코인 드롭
  * **인터랙션**: 걱정 칩을 탭하면 저금통 입구로 쏙 들어가는 애니메이션 및 저금통 찰랑거림 효과.

---

## 10. 333 나비포옹 (333 Butterfly Hug)
* **추천 대상**: 불안하거나 스스로를 너무 엄격하게 다그치게 되는 순간.
* **방법**: 양팔을 X자로 감싸 안고, '괜찮아' 3번, '그럴 수도 있지' 3번, '뭐 어때' 3번을 말하며 토닥입니다.
* **효과**: 뇌의 양쪽을 번갈아 두드리는 부드러운 자극(EMDR 기법)과 다정한 위로가 마음을 안정시킵니다.
* **💻 웹 구현 & UI 모습**:
  * **라우트/모듈**: 인터랙티브 햅틱 & 탭 토닥임 카운터
  * **인터랙션**: 화면의 양쪽 나비 잎사귀를 번갈아 탭할 때마다 햅틱 진동과 함께 위로 문구가 부드럽게 페이드인.

---

## 11. 미래그림일기 (Future Picture Diary)
* **추천 대상**: 원하는 미래가 막연하기만 한 사람.
* **방법**: 가장 이상적인 미래의 모습을 글로 구체화하고 이미지로 그려보며 미래의 소망을 직관화합니다.
* **효과**: 막연한 소망보다 눈에 보이는 형태가 된 미래는 강한 삶의 방향성이 되어 줍니다.
* **💻 웹 구현 & UI 모습**:
  * **라우트/모듈**: 그림일기 프레임 & 캔버스 카드
  * **인터랙션**: 미래 다짐 문장 입력 시 파스텔 톤 일러스트 프레임 카드로 변환되어 '나의 미래 서재'에 아카이빙.
