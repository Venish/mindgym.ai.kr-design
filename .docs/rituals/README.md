# 🧘 일상을 회복하는 72가지 마음 리추얼 웹 UX/UI 설계 종합 가이드

본 가이드는 장재열 작가의 **「일상을 회복하는 72가지 마음 리추얼 (마이크로 리추얼 가이드)」** 저작 원본을 바탕으로, 72가지 마이크로 리추얼을 **마인드짐(MindGym) Next.js 웹 서비스**에서 최적의 정서적 UX와 인터랙션으로 경험할 수 있도록 구성한 **종합 웹 구현 명세서**입니다.

├── PART3_EMOTION_AWARENESS_RITUALS.md  # 제3부: 자기 감정과 마음을 잘 모르겠는 사람을 위한 리추얼 (23~32번)
├── PART4_SELF_EXPLORATION_RITUALS.md  # 제4부: 나를 더 알고 싶은 사람을 위한 리추얼 (33~45번)

## 💡 72가지 리추얼의 웹 인터랙션 구현 패러다임 (UX Types)

72가지 리추얼은 웹 화면에서 다음과 같은 **4가지 표준 인터랙션 모듈**로 구현됩니다.

| 웹 인터랙션 타입 | 대표 리추얼 예시 | 웹 구현 및 컴포넌트 연출 방안 |
| :---: | :--- | :--- |
| 🎧 **Audio Guided (오디오 가이드형)** | 미소 명상, 횡경막 호흡, 바디스캔 | 가이드 음성 재생 + 호흡 파동 애니메이션 + 자막 싱크 (`/player/[id]`) |
| 📝 **Interactive Writing (마이크로 글쓰기형)** | 걱정유통기한라벨링, 거절 연습장, 불평일기 | 1~3줄 전용 포커스 카드 입력 + 물리적 애니메이션(파쇄, 지우개 효과) |
| ⏱️ **Timer & Action (타이머 & 멈춤형)** | 시선고정명상, 1분 정리, 오프먼트 | 3분/5분 카운트다운 타이머 + 앰비언트 백색소음 + 화면 디톡스 잠금 |
| 🎨 **Visual Canvas (비주얼 & 카드 캔버스형)** | 원라인드로잉, 공간사진 101, 오늘의 색깔 | HTML5 Canvas 기반 캔버스 그리개, 이미지 업로드, Palette Picker |
