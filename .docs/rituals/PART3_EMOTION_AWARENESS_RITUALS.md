# 🟣 [RITUAL-PART 3] 자기 감정과 마음을 잘 모르겠는 사람을 위한 리추얼 (23 ~ 32번)

본 문서는 뭉뚱그려진 감정을 또렷이 들여다보고 상황과 마음을 분리해 객관적으로 정리하도록 돕는 **23번부터 32번 리추얼의 원본 내용 및 웹 UI 구현 스펙 문서**입니다.

---

## 23. 감정개명 (Emotion Renaming)
* **추천 대상**: 자기 감정을 '짜증', '우울'처럼 큰 덩어리로만 뭉뚱그리는 사람.
* **방법**: 느낀 감정에 '화' ➔ '서운함', '불안' ➔ '준비가 덜 된 마음'처럼 구체적인 새 이름을 붙여봅니다.
* **효과**: 이름을 바꾸는 것만으로 감정을 대하는 태도가 바뀌고 압도감이 줄어듭니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 감정 태그 개명 칩 캔버스. 큰 감정 칩을 탭하면 3가지 구체적 섬세 감정어로 분개되는 모션.

---

## 24. 마음날씨 기록 (Mind Weather Report)
* **추천 대상**: 기분이 왜 가라앉는지 모르겠는 사람, 감정과 상황을 혼재한 사람.
* **방법**: 기상청 일기예보 표처럼 날씨(외부 사건)와 기온(내 마음 상태)을 분리하여 기록합니다.
* **효과**: 사건과 내 감정 반응 사이의 거리를 확인하고 패턴을 파악하게 돕습니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 마음 날씨 예보관 표 렌더링. [외부 날씨: 흐림(회의 중 반려)] vs [내 기온: 47도 열받음] 2열 대비 카드.

---

## 25. Y 7 질문법 (7 Whys Writing Therapy)
* **추천 대상**: 표면 감정만 맴돌 뿐 진짜 내 행동의 원인을 모르겠는 회피형 성향의 사람.
* **방법**: 고민에 대해 "왜?"라는 질문을 7번 연속으로 던지며 마음의 뿌리에 도달합니다.
* **효과**: 깊은 자기 탐색을 통해 표면에 숨겨진 진짜 문제의 원인을 알아차리게 됩니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: Step-by-Step 7단계 Q&A 아코디언 카드. 1번 답을 쓰면 2번 "왜 그렇게 느꼈나요?" 질문이 확장됨.

---

## 26. 객관화일기 (Objectivity Journal)
* **추천 대상**: 감정에 휩쓸려 상황을 실제보다 크게 받아들이는 사람.
* **방법**: 사관이 역사를 기록하듯 감정을 모두 빼고 오직 일어난 '사실'만을 건조하게 적습니다.
* **효과**: 감정의 색안경을 벗고 사건의 실제 크기를 있는 그대로 마주합니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 감정 필터링 에디터. 텍스트 입력 시 주관적 형용사를 감지하여 사실 문장으로 정돈해 주는 툴.

---

## 27. 사실과 견해 분리하기 (Fact vs Opinion Separation)
* **추천 대상**: 작은 일을 자기 식대로 확대 해석해 괴로워하는 사람.
* **방법**: 속상한 일을 적은 뒤 '사실'에는 동그라미(⭕), '내 견해(해석)'에는 밑줄(―)을 칩니다.
* **효과**: 나를 괴롭히는 것이 사실이 아니라 대부분 내 해석이었음을 시각적으로 파악합니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 2분할 하이라이터 툴. 텍스트 블록 선택 탭 ➔ 🔵[사실(Fact)] vs 🟡[해석(Opinion)] 태그 칩 분류.

---

## 28. 불평일기 (Grumble & Acceptance Journal)
* **추천 대상**: 부정적 감정을 억누르기만 하고 죄책감을 느끼는 사람.
* **방법**: 마음껏 불평불만을 쏟아내 적은 뒤, 마지막엔 '내가 그렇게 느낄 만했다'는 증거로 마무리합니다.
* **효과**: 감정을 억누르지 않고 충분히 느낀 뒤 수용하는 건강한 감정 해소를 돕습니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 불평 쏟아내기 노트 ➔ 마지막 "충분히 그럴 수 있었어" 도장 쿵 날인 애니메이션.

---

## 29. 긍정해석연습 (Neutral Insight Practice)
* **추천 대상**: 힘든 일을 억지 긍정으로 덮거나 부정에만 매몰되는 양 극단의 사람.
* **방법**: 억지 긍정이 아니라 '이 상황에서 내가 얻거나 배운 것'을 중립적으로 발견해 적습니다.
* **효과**: 사건 자체는 바꿀 수 없어도 중립적인 인지의 연습을 통해 성장의 시선을 키웁니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: [힘든 사건 카드] ➔ [이 일에서 건진 1가지 배움] 입력 인터랙션.

---

## 30. 스몰 모닝페이지 (3-Min Small Morning Page)
* **추천 대상**: 아침마다 머리가 복잡하고 이유 없는 불행감이 잦은 사람.
* **방법**: 잠에서 깬 직후 3분 타이머 동안 떠오르는 생각을 정돈 없이 빠르게 쏟아 적습니다.
* **효과**: 머릿속을 비우고 가수면 상태에서 누르던 진짜 감정을 안전하게 꺼냅니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 3분 카운트다운 쾌속 타이머 에디터. 3분이 지나면 자동 저장 및 카드 접힘 모션.

---

## 31. 어른이 그림일기 (Crayon Picture Journal)
* **추천 대상**: 글로 감정을 표현하기 어렵거나 정제된 언어에 갇힌 사람.
* **방법**: 어린이용 그림일기장 칸에 크레파스로 서툰 그림과 짧은 한 문장을 그립니다.
* **효과**: 잘 써야 한다는 부담을 내려놓고 솔직하고 순수한 감정을 끌어냅니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 캔버스 질감 그림판 + 알록달록 크레파스 붓 툴 캔버스 뷰.

---

## 32. 마음필사 (Mind Transcription)
* **추천 대상**: 독서가 부담스럽고 책을 읽어도 남는 게 없다고 느끼는 사람.
* **방법**: 책을 읽다가 내 마음을 건드린 '단 한 줄'을 발견하면 멈추고 필사하여 기록합니다.
* **효과**: 완독 부담 없이 내가 주체적으로 반응한 심리학적 문장 리스트를 모아갑니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 한 줄 필사 구절 인용구 카드 생성기 (`"오늘 내 마음에 남은 한 줄"`).
