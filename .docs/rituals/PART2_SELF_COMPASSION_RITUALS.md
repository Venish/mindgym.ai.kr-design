# 🔵 [RITUAL-PART 2] 자기에게 엄격하고 자책이 많은 사람을 위한 리추얼 (12 ~ 22번)

본 문서는 자신을 다그치고 탓하는 마음에서 벗어나 스스로를 변호하고 다독이는 자기 옹호의 **12번부터 22번 리추얼의 원본 내용 및 웹 UI 구현 스펙 문서**입니다.

---

## 12. 내편일기 (My Side Diary)
* **추천 대상**: 자기 잘못에만 가혹한 사람, 늘 자기 탓부터 하는 사람.
* **방법**: 내가 완전히 내 편이 되어 유난스러울 정도로 나를 변호하는 일기를 씁니다. ("우리 애 기죽게 왜 그래요!" 톤).
* **효과**: 세상 누구도 내 편을 들어주지 않는 것 같을 때 나만큼은 무조건 내 편이 되어보는 자기자비 연습입니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 내편 변호사 챗봇 UI 템플릿. "내가 억울했던 일" 입력 시 내 편을 들어주는 맞춤 격려 멘트 자동 생성 카드.

---

## 13. 미고사 (Sorry·Thank you·Love Messages)
* **추천 대상**: 늘 남에게는 다정하면서 자신에게는 엄격한 사람.
* **방법**: '미안합니다, 고맙습니다, 사랑합니다'를 자기 자신에게 아침/점심/저녁 메시지로 나누어 전합니다.
* **효과**: 남에게는 쉽게 하던 따뜻한 말을 나에게 해주며 어색함을 허물고 스스로를 돌봅니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: [미안해], [고마워], [사랑해] 3색 카드 탭 선택 ➔ 나에게 보내는 푸시 메시지 알림 카드 설정.

---

## 14. 자존감 칠판 (Self-Esteem Blackboard)
* **추천 대상**: 자기 비하가 습관이 된 사람, 칭찬을 들어도 금세 흘려보내는 사람.
* **방법**: 문득 떠오른 내 장점이나 들었던 칭찬을 칠판에 적어두고 매일 소리 내어 읽습니다.
* **효과**: 쉽게 잊어버리는 나에 대한 긍정적인 말을 눈에 보이는 곳에 붙여 마음에 새깁니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 파스텔 칠판 캔버스 뷰. 칭찬 스티커 칩을 칠판에 드래그하여 붙이고 음성 낭독 모드 지원.

---

## 15. 공수치 폭풍칭찬 (Cringe Over-Praise)
* **추천 대상**: 자기 칭찬이 너무 어색하고 민망한 사람.
* **방법**: 오버스러운 폭풍 칭찬 메시지를 거울을 보며 읽어봅니다. 민망함 속에서 공감성 수치를 느끼며 웃어봅니다.
* **효과**: 민망함과 웃음이 무거웠던 마음을 가볍게 풀어주어 자기 긍정의 문턱을 낮춥니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 거울 셀카 프레임 & 팝아트 폭풍 칭찬 텍스트 롤링 디스플레이.

---

## 16. 오늘의 상장 (Today's Award Certificate)
* **추천 대상**: 자기 자신에게 냉정한 사람, 평범한 하루를 무가치하게 느끼는 사람.
* **방법**: 오늘의 나를 위한 상장('성실상', '잘 버틴 상', '배려상')을 직접 만들어 수여합니다.
* **효과**: 남이 알아주지 않아도 내가 나의 하루를 인정하며 작은 성취감을 쌓아갑니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 상장 양식 생성기. 상장 제목, 수상자(내 이름), 수여 사유 입력 ➔ 금박 직인 도장 날인 애니메이션.

---

## 17. 달의 뒷편 롤링페이퍼 (Moon's Dark Side Rolling Paper)
* **추천 대상**: 자기 단점에 갇혀 있는 사람, 자책이 많은 사람.
* **방법**: 나의 성격 단점을 적으면 이를 장점(예: 예민함 ➔ 섬세함, 우유부단 ➔ 신중함)으로 재해석합니다.
* **효과**: 단점의 반대편을 바라보며 나를 입체적으로 이해하는 계기가 됩니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 단점 ➔ 장점 변환 카드. 단점 키워드 선택 시 "달의 뒷편" 반전 카드가 뒤집히며 긍정 재해석 장점 노출.

---

## 18. 지우개 테라피 (Eraser Therapy)
* **추천 대상**: 오래된 상처나 트라우마가 된 말 한마디가 마음에 남아 아픈 사람.
* **방법**: 상처가 된 말을 연필로 적고, 지우개로 깨끗이 지운 뒤 그 위에 볼펜으로 나를 변호하는 글을 덮어씁니다.
* **효과**: 물리적으로 기억을 지우고 새로운 자기 옹호의 목소리를 영구히 남기는 경험을 제공합니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 디지털 지우개 캔버스. 마우스/터치 지우개 툴로 연필 글씨를 쓸어 지우고 볼펜 덮어쓰기 기능.

---

## 19. 셀프 하이파이브 (Self High-Five)
* **추천 대상**: 하루를 힘없이 시작하는 사람, 작은 의식으로 기운을 얻고 싶은 사람.
* **방법**: 현관이나 화면에 손바닥 모양을 두고 외출/귀가 시 하이파이브를 칩니다.
* **효과**: 단순한 물리적 스킨십 동작이 "오늘도 잘해보자"는 강한 출발의 신호가 됩니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 3D 손바닥 패드 터치. 화면 손바닥을 탭하면 "짝!" 사운드와 함께 스파크 진동 햅틱 발생.

---

## 20. 원라인드로잉 (One-Line Drawing)
* **추천 대상**: 습관을 만들고 싶지만 무언가를 해내야 한다는 부담이 큰 사람.
* **방법**: 매일 부담 없이 딱 하나의 한 줄 선만 긋는 최소한의 습관 리추얼입니다.
* **효과**: 행위 자체의 부담을 제로로 만들어 의지 달성 효능감을 쌓아갑니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 일일 1선 캔버스. 손가락으로 선 한 줄을 그으면 오늘 일자에 초록 실천 잇기 선이 연결됨.

---

## 21. 거절 연습장 (Refusal Practice Journal)
* **추천 대상**: 부탁을 거절하지 못해 늘 자신을 소진하는 착한 사람 콤플렉스가 있는 사람.
* **방법**: 거절하지 못했던 일들을 저녁에 모아 단호하고 다정한 거절 멘트를 써봅니다.
* **효과**: 거절 문장을 미리 연습해두어 실제 비슷한 순간이 올 때 쉽게 말할 수 있도록 돕습니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 거절 멘트 보관 카드 템플릿 ("죄송하지만 지금은 어렵습니다" 등 상황별 멘트 연습 카드).

---

## 22. 투데이 확언 (Today's Action Affirmation)
* **추천 대상**: 거창한 확언이 공허하게 느껴지고 지친 사람.
* **방법**: 막연한 먼 미래 대신 '오늘 내가 할 수 있는 작은 한 걸음'을 발 붙여 확언합니다.
* **효과**: 현실 가능한 확정적 미래를 쌓아 거시적인 미래에 대한 기대감을 높입니다.
* **💻 웹 구현 & UI 모습**:
  * **인터랙션**: 오늘의 한 걸음 확언 칩 셋업. "오늘 나는 10분 산책한다" 셋업 ➔ 완수 시 도장 쿵 클릭.
