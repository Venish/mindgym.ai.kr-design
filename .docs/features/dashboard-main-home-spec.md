# [P-18-v3] 마음의 쉼터 및 누적 실천 대시보드 화면 (MindGym Gentle Dashboard)

본 화면은 기존의 강박적인 게임형 '스트릭 리셋' 및 '쉴드' 차감 구조를 걷어내고, 자기결정성 이론(Self-Determination Theory)과 자기자비(Self-Compassion) 이론에 기반하여 설계된 **지속 가능한 마음 돌봄 아카이브형 대시보드**입니다.

## ⚙️ 화면 영역별 UI 상세 명세

1. **상단 덤벨 성장 프로그래스 바 (1)**:
   * **수치의 고상한 시각화**: 과도하게 화려한 보석이나 포인트 연출 대신, 정제된 그린-민트 톤의 덤벨 성장선으로 스스로 자라나는 마음 근력을 시각화합니다.
   * **데이터 맵핑**: `totalDumbbells` 수치를 바탕으로 레벨 단계를 렌더링합니다.

2. **이달의 마음 정원 (2) - *핵심 리디자인 영역***:
   * **그리드형 누적 캘린더**: 전통적인 연속 스트릭(Streak) 불꽃 대신, 해당 월의 전체 날짜가 그리드로 배치된 달력 뷰입니다.
   * **아이콘 상태 전이**:
     * **`[실천]` (초록 불꽃)**: 당일 체크인이나 자율 리추얼을 단 하나라도 완수한 날.
     * **`(휴식)` (연한 민트 원)**: 체크인을 하지 못했으나 패널티 없이 '자연스러운 쉼'으로 처리된 날. (이전 연속 일수가 초기화되는 페널티가 존재하지 않음).
     * **`[빈 칸]` (회색 점선 원)**: 아직 도래하지 않은 날짜.
   * **정서적 지지 하단 카피**: 강박적인 카피 대신, "하루 쉬어가는 것도 건강한 마음 단련의 일부입니다."와 같이 유저의 완벽주의를 다독여주는 자비 문구를 배치합니다.

3. **오늘의 마음 체크인 배너 (3)**:
   * **쉬어간 다음 날의 웰컴 오프너**: 어제 하루 체크인을 쉬고 오늘 처음 진입한 경우, "기록이 깨졌습니다"가 아니라 **"어제 마음껏 쉬어가며 에너지를 완충하셨나요? 오늘의 마음 날씨는 어떤가요?"**라는 환영 인사로 마음을 편안하게 열어줍니다.

## 🧠 프론트엔드 연동 및 전역 상태 갱신 규칙 (Next.js)

'스트릭 쉴드'와 '강제 리셋'이 사라짐에 따라, 전역 상태 엔진과 데이터 관리 체계가 아래와 같이 극적으로 단순화되고 우아해집니다.

```typescript
// /src/context/MindGymContext.tsx (업데이트 반영부)

interface MindGymState {
  totalDumbbells: number;
  completedDaysInMonth: string[]; // 실천 완료한 날짜 배열 (예: ["2026-08-01", "2026-08-02"])
  restDaysInMonth: string[];      // 명시적으로 휴식한 날짜 배열
  currentIntention: string;
}

// 연속 리셋 로직이 제거됨에 따라, 백엔드 자정 크론탭이나 
// 클라이언트 진입 시의 '초기화 위협(AT_RISK)' 상태 체크 연산이 완전히 생략됩니다.
// 사용자는 언제 앱을 켜더라도 본인의 누적 성과가 그대로 보존된 정원을 만나게 됩니다.
```

## 🧘 인지적 가치 (Psychological Value)
* **내재적 동기(Intrinsic Motivation)의 극대화**: "연속 기록을 지키기 위해 억지로 켠다"는 의무감을 "내 마음의 정원을 예쁜 불꽃으로 채워나간다"는 자발적 수집 의지 및 자기 주도적 몰입으로 전환합니다.
* **이탈 방지의 본질적 개선**: 연속 기록이 깨지면 이탈율이 급증하는 기존 스트릭의 최대 단점을 보완하여, 하루 쉬어가도 기록 보존에 손실이 없기 때문에 언제든 죄책감 없이 다시 접속할 수 있습니다.
