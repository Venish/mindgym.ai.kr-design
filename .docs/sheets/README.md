# 🌿 MindGym 원본 데이터 및 시트별 시스템 구성 분석서

Google Spreadsheet (**`MindGym_개발데이터`**) 9개 시트의 원본 데이터 및 사이트 화면 구성과의 연동 분석 문서입니다.

## 🛠️ 데이터 가공 및 활용 안내
* 모든 시트 데이터는 표준 `UTF-8` CSV 형식과 Readable한 GitHub Flavored Markdown 표 형태로 제공됩니다.
